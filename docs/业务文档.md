# 个人自用刷题App 完整业务规格文档

> 用途：交付开发、设计
> 核心前提：单用户本地工具，**默认纯离线**；AI 功能为可选增强，仅在用户主动配置并开启后发起网络请求
> 文档版本：v2.1 ｜ 更新日期：2026-09-14

## 1. 核心业务定位

- **目标用户**：个人自用，**移动端优先**（Android 为主，桌面端 Windows/Linux 保留）。
- **用户痛点**
  1. 通用刷题App题库固化，无法导入自己整理的习题。
  2. 第三方App充斥会员、广告、社交等无关功能造成干扰。
  3. 刷题容易分心、难以坚持：需要**沉浸式体验与心理暗示**帮助"想刷题、认真刷题"。
  4. 简答题无机器判分、答错后解析不足：需要**可选 AI 判题与 AI 错题解析**作为增强（自备 Key，成本自担）。
  5. 希望学习数据保存在本机；需要错题复盘、正确率统计定位薄弱点。
- **产品定位**：一款**移动端沉浸式刷题工具**，支持自定义导入题库，完成刷题、错题整理、复习复盘；无广告无社交；通过无边框全屏设计、深浅双主题、轻量激励文案营造专注氛围；可选接入 AI 判题与解析。

## 2. 业务边界

### 需要做

- CSV/Excel 格式导入自制题库
- 本地刷题：单选、多选、判断、简答、填空
- 自动错题本、手动题目收藏
- 顺序/随机刷题模式、错题复习模式
- 做题记录、正确率基础统计
- 题目按题库集、标签管理
- 全部数据本地优先存储
- 数据备份导出、备份恢复
- **无边框沉浸式 UI，浅色/深色双主题**
- **设置页**：主题、AI 相关配置
- **可选 AI 能力**：简答 AI 判题、答错后 AI 错题解析（用户自备 API Key，默认关闭）

### 坚决不做

- 多用户、注册登录账号体系
- 付费、会员、广告、商城
- 社区、分享、排行、**社交化打卡**
- 爬虫抓取网络公开题库
- 直播、网课、资料下载
- 题目搜索、自定义组卷、单题笔记、限时刷题、薄弱点分析、增量备份
- 除用户配置的 AI 接口外，**任何其他网络请求、埋点、上报**
- AI 判题扩展到客观题/填空题（成本控制，MVP 仅 essay）
- AI 生成题目、AI 语音、AI 对话辅导

## 3. 核心业务场景 & 用户旅程

1. **导入题库**：导入CSV/Excel题库文件；解析题目、选项、答案、解析、标签；格式错误给出提示，损坏数据不导入。
2. **题库管理**：查看题库集；新建/重命名/删除题库；给题目打标签；手动新增、编辑、删除单道题目。
3. **发起刷题**：选择题库或标签筛选，支持顺序刷题、随机刷题；中途退出自动保存进度；进入刷题后**自动切换沉浸模式**（移动端隐藏导航，全屏专注）。
4. **答题过程**
   - 单选/多选/判断：提交即展示答案与解析；多选必须全部匹配才算答对，错选、少选、多选均判定错误，答错自动加入错题本。
   - 填空：用户输入作答文本，机器自动判分；支持多标准答案；允许手动覆写对错状态；机器判错自动进入错题本。
   - 简答：用户输入作答；
     - **未启用 AI 判题**：手动标记对错；
     - **启用 AI 判题**：提交后自动调用 AI 判题，展示"AI 判题"结果与理由，用户仍可手动覆写（手动优先级最高）。
   - 答错后：展示题目自带解析；**启用 AI 解析时**额外展示"AI 错题解析"（异步生成、结果缓存）。
   - 支持上一题、下一题；可中途退出保存刷题进度。
5. **错题&收藏**：答错自动进错题本；手动收藏/取消收藏；错题本移除错题仅清除标记，原题保留。
6. **复习**：刷错题集、刷收藏题目，支持标签筛选。
7. **数据查看**：查看刷题统计数据。
8. **设置**：主题切换（跟随系统/浅色/深色）；AI 配置（Base URL、API Key、模型名、测试连接）；AI 判题开关、AI 解析开关、激励文案开关。
9. **备份恢复**：导出全量数据包备份；从备份文件恢复本地数据。

## 4. 题库与题目业务规则

### 4.1 题目类型枚举

|类型标识|题型|判分规则|
|---|---|---|
|single|单选题|机器判分，1个正确选项（所选选项文本去除首尾空格后与答案完全一致），答错自动入错题|
|multi|多选题|机器判分，必须全部匹配才算正确，答错自动入错题|
|judge|判断题|机器判分，true/false（忽略大小写与首尾空格），答错自动入错题|
|essay|简答题|**AI 判分（可选）或手动标记**，无机器判分；判错/标错后进入错题本|
|fill|填空题|机器判分，支持多标准答案；允许用户手动覆写对错状态|

#### 填空题判分细节

1. 多标准答案使用英文分号 `;` 分隔，如 `TCP;传输控制协议`，命中任意一个即为正确。
2. 匹配规则：去除首尾空格，**大小写敏感**，中间空格原样比对。
3. 提交后自动判分；机器判定错误自动加入错题本。
4. 用户可手动覆盖对错结果，手动状态优先级高于机器判分。
5. 答题结果页展示：用户输入内容、全部参考答案、解析。

#### 简答题判分细节（含 AI 判题）

1. 简答题**无机器判分**，最终对错由"手动标记"或"AI 判题 + 手动覆写"决定。
2. 判题结果优先级（从高到低）：**手动覆写 > AI 判题 > 机器判分**。
3. 未启用 AI 判题时：提交后仅保存作答，由用户手动标记对错。
4. 启用 AI 判题时：提交后自动调用 AI 判题，展示结果与简短理由；AI 判题失败则回退手动标记。
5. AI 判题为"错"或用户手动标"错"后进入错题本；用户覆写为"对"则移出错题。

### 4.2 CSV/Excel 导入字段

|字段|是否必填|说明|
|---|---|---|
|题目ID|否|内部标识，导入自动生成，用户不用填写|
|题目类型|是|single/multi/judge/essay/fill|
|题干|是|题目文本|
|选项|否|单选、多选使用；简答、填空为空|
|正确答案|是|单选A；多选A,B；判断true/false；简答填写参考；填空多答案用`;`分隔|
|解析|否|参考答案解析文本|
|标签|否|多个标签英文逗号分隔，例：数据库,第三章|
|所属题库集|否|归属题库集合|

#### 导入校验规则

1. 支持 `.csv`/`.xlsx`/`.xls` 文件，字段规范完全一致。
2. 题干为空、类型非法、答案格式错误 → 跳过该行，输出错误行号提示，不写入题库。
3. 重复题干：保留原有题目，不重复新增。

### 4.3 题库集规则

- 可新建、重命名、删除题库集。
- 一道题目仅归属一个题库集，可附加多个标签。
- 删除题库集：二次确认，删除后集合内所有题目一并删除。

### 4.4 标签规则

- 标签依附题目，不属于题库集；一题可多标签。
- 支持按标签筛选题目、筛选错题。
- 删除标签仅清除题目标记，不删除题目。

### 4.5 错题业务规则

1. 单选/多选/判断答错自动加入错题本；
   - 填空题：机器判错自动加入错题，用户手动修改为答对则移出错题；
   - 简答：AI 判错或手动标错加入错题本，覆写为对则移出。
2. 同一题目多次做错，错题本仅存一条，记录做错次数。
3. 错题本"移出错题"：仅移除错题标记，原题、做题记录完整保留。
4. 修改原题题干/答案，**不清除历史错题、做题记录**。

### 4.6 收藏题目规则

- 手动点击收藏 / 取消收藏；收藏独立于错题。
- 删除原始题目，自动取消该题收藏。

### 4.7 备份数据包规则

- 导出：完整数据包包含题目、做题记录、错题标记、收藏、标签、设置项、AI 判题结果与 AI 解析缓存（8 张表）。
- 恢复：导入备份包**覆盖本地全部数据**，恢复前弹窗风险提示。
- 备份包为自定义格式，不和普通CSV互通。
- **API Key 参与备份**：导出即含 Key（明文），用户应妥善保管备份文件；恢复后 AI 配置一并还原。

## 5. 主题与无边框沉浸式设计

### 5.1 设计目标

- 移动端全屏沉浸：内容区最大化，系统状态栏与导航栏不打断刷题（Edge-to-Edge）。
- 桌面端：自定义无边框标题栏（已实现），与窗口内容同主题。
- 减少视觉噪音：低饱和配色、弱化进度数字、留白呼吸感。

### 5.2 主题模式

|主题|说明|
|---|---|
|跟随系统|默认。随系统深色模式自动切换|
|浅色|始终浅色|
|深色|始终深色，夜间刷题友好|

- 三态在设置页切换，实时生效，无需重启。
- 主题选择持久化本地（settings 表）。

### 5.3 配色基调（设计约束）

**浅色主题**
- 页面背景 `#F5F6F8`，卡片 `#FFFFFF`，主文字 `#1F2328`，次要文字 `#6B7280`
- 主色（品牌蓝）`#3B82F6`，答对绿 `#16A34A`，答错红 `#DC2626`
- 边框 `#E5E7EB`，沉浸刷题背景 `#FFFFFF`

**深色主题**
- 页面背景 `#0F1115`，卡片 `#1A1D24`，主文字 `#E6E8EB`，次要文字 `#9CA3AF`
- 主色（品牌蓝）`#60A5FA`，答对绿 `#4ADE80`，答错红 `#F87171`
- 边框 `#2A2E37`，沉浸刷题背景 `#12151B`（避免纯黑刺激，柔化对比）
- 深色下禁用高饱和纯白大色块，答案/解析卡片用暗色卡片 + 低饱和色边

### 5.4 无边框与沉浸式规则

1. **移动端**：
   - 系统状态栏透明/沉浸，内容延伸到状态栏区域（safe-area 处理）；
   - **一级导航仅 3 项**：刷题（首页）/ 题库 / 我的（收纳错题本、收藏、统计、备份恢复、设置），底部导航仅出现在非刷题页面；
   - **进入刷题自动隐藏顶栏与底部导航**，全屏只留题目卡；刷题中通过"退出刷题"按钮或系统返回键退出沉浸模式。
2. **桌面端**：
   - 自定义标题栏随主题变化（浅色白底/深色暗底），保留最小化、最大化、退出三按钮与拖拽。
   - 侧边栏分组展示：主功能组（刷题、题库）、复习与数据组（错题本、收藏、统计）、系统组（备份恢复、设置，置底）。
3. **通用**：
   - 弹窗、Toast、确认框必须同时适配两种主题，不得出现"深色模式下白底刺眼弹窗"。
   - 主题切换时过渡平滑（颜色 150ms 过渡）。

## 6. AI 功能业务规则（核心设计）

> AI 功能为**可选增强**：默认关闭；未配置或未开启时，App 保持 100% 离线，行为与无 AI 版本完全一致。

### 6.1 接口协议

- 采用 **DeepSeek Chat Completions（OpenAI 兼容）**：`POST {base_url}/v1/chat/completions`。
- 用户可配置：**Base URL、API Key、模型名**，兼容 OpenAI、DeepSeek、通义千问等绝大多数服务。
- 请求体标准 `{ model, messages, temperature, response_format }`；要求模型输出**严格 JSON**。

### 6.2 设置项

|设置项|说明|默认值|存储|
|---|---|---|---|
|AI Base URL|OpenAI 兼容接口地址（DeepSeek 兼容）|`https://api.deepseek.com`|settings 表明文|
|AI API Key|密钥，界面密文显示，支持一键清空|空|settings 表明文（本机）|
|AI 模型名|模型标识|`deepseek-v4-pro`|settings 表明文|
|AI 判题|是否启用简答 AI 判题|关|settings 表|
|AI 解析|是否启用答错后 AI 解析|关|settings 表|
|激励文案|连续答对轻文案提示是否开启|开|settings 表|
|主题|跟随系统 / 浅色 / 深色|跟随系统|settings 表|

- API Key 为空或未开启对应开关时，该能力视为不可用，UI 不出现相关入口/标识。
- 设置页提供"测试连接"按钮：发起一次最小请求验证 Key/地址/模型可用性，返回成功或错误信息。

### 6.3 AI 判题规则（essay 简答）

**触发条件（全部满足）**
1. 题型为 `essay`；
2. 设置中"AI 判题"开关开启；
3. 已配置 API Key 且 Base URL、模型名非空。

**判题流程**
1. 用户提交简答作答 → 前端显示"AI 判题中…"（提交按钮 loading，不阻塞翻题）。
2. 调用 AI 接口，输入：题干、参考答案、用户作答。
3. 要求模型返回 JSON：`{"correct": 0|1, "reason": "简短理由(≤80字)"}`。
4. 判题结果写入做题记录 `ai_result` 字段，UI 展示"AI 判题：对/错 + 理由"。
5. AI 判为错 → 按错题规则加入错题本（可被用户覆写移出）。
6. 用户仍可**手动覆写**（优先级最高），覆写后展示以手动结果为准。

**失败降级**
- 网络错误、超时（10 秒）、Key 无效（401）、限流（429）、模型返回非 JSON 等 → 判题失败。
- 失败时 UI 提示"AI 判题不可用，请手动标记对错"，回退到手动标记模式，**不影响做题记录保存**。
- 连续失败熔断：见 6.6。

**不触发场景**
- 单选/多选/判断：机器判分已确定，**不调用 AI**。
- 填空：机器判分已确定，**不调用 AI**；对机器结果不认可时走手动覆写（不新增 AI 调用，节省成本）。

### 6.4 AI 错题解析规则

**触发条件（全部满足）**
1. 某次答题**最终判定为错误**（机器判错 / AI 判错 / 手动标错，以最终结果为准）；
2. 设置中"AI 解析"开关开启；
3. 已配置 API Key 且 Base URL、模型名非空。

**解析流程**
1. 判定为错后**异步**发起 AI 解析（不阻塞翻题、不阻塞下一题）。
2. 输入：题干、正确答案、用户错误作答、题型、题目自带解析（如有）。
3. 要求模型返回：错因分析文本（简洁、面向学习者，≤200字）。
4. 生成后展示在结果区的"AI 错题解析"卡片中，标记"AI 生成，仅供参考"。
5. **结果缓存**：解析结果按「题目ID + 用户作答内容哈希」写入本地 `ai_analysis_cache` 表；同一题**相同错误作答**再次出现时直接读缓存，不重复调用、不重复计费。

**失败降级**
- 失败或超时（15 秒）：静默降级为展示题目自带解析（如有）；无自带解析则不展示 AI 区，不打断刷题。
- 401 单独提示"API Key 无效，请到设置检查"。

### 6.5 判题结果优先级与统计口径

1. **单次作答最终结果** = `manual_result`（手动覆写）> `ai_result`（AI 判题）> `machine_result`（机器判分）。
2. 统计口径：以最终结果计入正确/错误数；`essay` 未判题且未手动标记的记录不计入正确率分母。
3. 错题本状态：最终结果为错 → 在错题本；覆写为对 → 移出（历史记录保留）。

### 6.6 成本保护、限流与熔断

1. **不重复请求**：同一次提交仅调用一次判题；解析走缓存（见 6.4）。
2. **会话级熔断**：同一刷题会话内 AI 调用**连续失败 3 次**（网络错误/401/429/超时），自动暂停本次会话的 AI 功能并在 UI 提示"AI 服务暂不可用，已暂停本次会话"；下次进入刷题会话自动恢复尝试。
3. **错误分类提示**：
   - 401 → "API Key 无效，请到设置检查"
   - 429 → "请求过于频繁，请稍后再试"
   - 超时/网络错误 → "AI 服务连接失败"
4. 每次调用产生费用由用户承担（按其 API 服务商计费）。

### 6.7 安全与隐私

1. API Key **明文存储于本机 SQLite**（单用户本机工具）：设置页密文显示；备份文件含 Key，需用户妥善保管。文档与 UI 均需提示该风险。
2. AI 调用仅向**用户配置的 Base URL** 发送：题干、参考答案、用户作答、题型等**答题相关数据**；不发送题库集、标签、统计等无关数据。
3. 用户删除 Key 并关闭开关后，App 恢复纯离线，无任何网络请求。
4. 请求与响应不落日志（不记录 API Key 与作答内容到日志文件）。

## 7. 心理暗示与沉浸式设计（产品层）

> 目标：通过潜移默化的方式，让用户"想刷题、认真刷题、沉浸刷题"。所有设计**克制、不打扰**，严禁弹窗轰炸。

1. **进入即刷**：App 打开默认进入「刷题」首页（一级 Tab 首位）；刷题页提供"继续上次会话"一键入口，降低启动摩擦；错题复习、收藏刷题在刷题首页提供快捷入口。
2. **专注模式**：刷题中移动端隐藏导航（见 5.4），仅保留题目、作答区与轻量进度条。
3. **进度弱化**：不强调"第 N/M 题"数字，改用顶部细进度条；避免数字带来的完成压力。
4. **轻量激励文案**：每连续答对 5 题，结果区出现一句随机轻文案（如"再刷一题""状态不错""手感来了"），1.5 秒后淡出，不打断操作；可在设置中关闭。
5. **完成反馈**：一组刷题结束后展示简短的完成反馈（"本组完成，正确率 xx%"），提供"再来一组/返回"。
6. **连续天数（本地）**：记录"最近连续刷题天数"，仅在本机展示轻提示（如"已连续刷题 3 天"）；**不做社交、不做分享、不做排行榜**。
7. **夜间舒适**：深色主题降低亮部刺激，适配睡前刷题场景。

## 9. 付费&会员规则

无会员、无付费、无内购；全部功能直接开放，无权限锁。**AI 调用产生的费用由用户向所选 API 服务商自行结算，与本 App 无关**。

## 10. 非功能业务规则

1. **登录身份**：无登录注册账号体系，打开App直接进入主界面。
2. **数据存储**：所有数据保存在设备本地；**仅 AI 功能按用户配置向指定地址发送答题相关数据**；卸载App本地数据丢失，依赖手动备份。
3. **刷题进度**：中途退出保存当前会话进度；切换/新建刷题会话旧进度作废。
4. **统计逻辑**：统计基于本地做题记录；删除题目同步删除该题做题记录，统计同步更新；AI 判题结果参与统计（见 6.5）。
5. **交互容错**：大批量导入展示加载提示，防止界面卡死；删除题库集、恢复备份等高危操作，二次弹窗确认；AI 调用失败静默降级，不影响核心刷题流程。
6. **离线优先**：未配置 AI 时所有功能离线可用；配置 AI 后网络异常仅影响 AI 能力，不影响刷题、判分（机器）、错题、收藏、备份。
